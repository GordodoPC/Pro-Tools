# 🎚️ NOVA DAW

**NOVA DAW** é um projeto de desenvolvimento de uma Digital Audio Workstation (DAW) para Windows, criada para oferecer um ambiente completo de gravação, edição, mixagem, masterização e produção musical.

Desenvolvida com **C++20, JUCE e CMake**, a aplicação busca combinar desempenho, baixa latência, uma interface moderna e ferramentas avançadas de produção de áudio.

O projeto utiliza **OpenAI Codex**, integrado ao Visual Studio Code, para auxiliar no desenvolvimento, além do **REA (Reverse Engineer Anything)** como ferramenta de pesquisa e análise técnica.

## 🎯 Objetivos

- Gravação e reprodução de áudio multipista.
- Edição de áudio não destrutiva.
- Mixer profissional com roteamento e automação.
- Suporte a plugins VST3.
- Produção musical e edição MIDI.
- Ferramentas de mixagem e masterização.
- Interface moderna e personalizável.
- Processamento de áudio otimizado para Windows.

## 🛠️ Tecnologias

- C++20
- JUCE Framework
- CMake
- Visual Studio Build Tools
- OpenAI Codex
- REA via MCP
