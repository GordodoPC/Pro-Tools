# Pro-Tools
🎚️ NOVA DAW — Estação de trabalho de áudio digital para Windows, desenvolvida em C++20 e JUCE. Projeto open-source inspirado em DAWs profissionais como Pro Tools, com foco em gravação multipista, edição de áudio, mixagem, masterização, MIDI e plugins VST3. Desenvolvido com apoio do OpenAI Codex e ferramentas de engenharia reversa.
